How the link is protected

  • The link holds a 128-bit random code. In production the server stores only a hash of it.
  • It expires by default and can be switched off by the boy or any senior member of staff.
  • The page tells search engines not to list it and sends no referrer.
  • No faces, surnames or set names by default. Photos, when added, are of things.
  • Every opening is written to the audit log.
  • Links stop working when a boy leaves Ludgrove.
